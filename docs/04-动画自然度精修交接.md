## 2. 已经落地的代码

### 抓附惯性与固定步接线

- `src/animation/climb.ts`：新增纯数值附件状态，记录 `generation/time/angle/angularVelocity/gather/leftFoot/rightFoot/ready/failed`。
- `captureClimbAttachment` 从抓附前速度与规范几何播种角速度，不读取上一渲染帧。`stepClimbAttachment` 使用重力、阻尼、有限摆角，随后主动收拢并顺序贴脚；预算 `CLIMB_ATTACH_DURATION = 0.9` 秒，正常结束就绪，零惯性不会无限挂持。
- `src/motion/solver.ts`：`stepFlight` 在抓附清零前另返 `grabVelocity`；世界根接触速度仍清零，`stepBody` 的原返回形状不变。
- `src/runtime/controller.ts`：每个物理子步推进附件，只有就绪后沿边行进；同接触、参考系与代次才插值。取消后保留挂持并继续局部收敛，释放、放置、销毁清旧状态。规划成本引用 0.9 秒，而非复制另一个时间常量。

### 脚尖、身体与原地跑

- `src/animation/rig.ts` / `src/rendering/canvas.ts` 共用 `FOOT_HEEL_LENGTH = 0.035` 和 `FOOT_TOE_LENGTH = 0.075`。
- 脚目标改为脚尖，脚段朝向墙体并略微抬趾，反算脚踝后解两段腿 IK；支撑验证不再把脚踝在墙上当作脚尖接触。
- 胸盆骨由抓附胸点与附件摆角构造；攀爬不再使用通用屏幕 y 的腿长补偿。头颈稳定、局部重心随路程相位小幅变化；膝分支优先墙外解。
- `IN_PLACE_CADENCE = 1.2` 完整周期/秒（约 2.4 次交替抬腿/秒），由同一正弦相位驱动对侧肘摆；肘角接近直角，根位置与平台行程不变。

### 坐下与起身

- `SIT_DOWN_DURATION = 0.85` 秒，已有分段屈膝、后撑、臀落与不对称伸腿；胸部有小幅呼吸，臀、手掌和脚跟仍受接触约束。
- `SIT_STAND_DURATION = 1.05` 秒：捕获当前脚部位置/角度，依次收脚再蹬起；Controller 已传真实起身时长。正在起身时新请求只替换完成回调，不重置动作时间。
- 其他起身仍保留原 `STAND_DURATION`，没有顺带重构其他动作。

## 4. 剩余工作：按顺序开展

### P0：先看真实连续运动，不先继续猜参数

1. 重建 `dist`，启动 example；保持导入 `dist/index.mjs`，不要改成源码 alias。
2. 手动模式使用真实按钮：攀爬起点/竖墙往返、84°斜边往返、坐下/起身、原地跑。默认 16 px 需验证，24 px 或合适较大尺寸用于看清关节；不能为了截图绕过实际空间限制。
3. 保存录屏，慢放并抽取抓附、摆动、贴脚、支撑、换脚与起身的连续帧。小幅根快照变化不能代替骨架观察，静态姿态图不能证明惯性自然。
4. 优先判断：双手是否一直抓稳；下身是否真的摆近墙而非直接拖过去；脚尖是否顶住而脚跟悬空；屈膝与蹬伸是否由重心带动；原地跑是否像高抬腿而非快速抖腿。

### P1：补强攀爬几何与接触连续性

- **双腕可达域**：当前靠规范胸点与 IK 维持，需对完整附件期和两个坡向密集采样，校验实际腕端点到达目标，不能只检查目标坐标。必要时有限调整胸盆骨，但不得拉伸或逐关节裁切。
- **膝分支切换**：目前比较两个分支并优先墙外解。需要检查整周期是否突然反折；若出现跳变，应连续选择可行分支或调整局部盆骨，不扩大骨长容差掩盖问题。
- **脚尖漂移/脚跟墙外**：补足倾斜墙、左右镜像、全周期、支撑/摆动切换与停止后的端点断言。使用 Canvas 共用的脚长计算，不能再断言 ankle = wall。
- **附件就绪判定**：当前附件按有限时间和权重就绪，需核对真正 FK 可达接触是否与 ready 同步。若不成立，增加有限几何确认；不能根先爬、脚后贴。
- **强惯性、低重力及中断**：检查不同 vx/vy、4–20 的对外重力、暂停/unknown、取消挂持、释放重抓。确认局部状态不依赖显示帧率且不把上次摆角带入新抓附。
- 共享脚长目前已经覆盖 rig/Canvas/相关接触测试；`climb.ts` 的规范几何及部分旧步态表达式仍有相同数值，后续若调整脚长需核对，避免把不同用途的小数盲目全局替换。

### P1：补强坐起和原地跑

- 坐姿：补“后撑先于臀落”“双脚错开伸展”、坐稳呼吸不漂移、短 duration/取消/转身等中断的全时序测试；旧接触断言通过不代表过程已自然。
- 起身：检查收回一脚时另一脚是否真实支撑，双手放开是否太早；捕获脚位置时的方向与镜像要一致，不能折返到原始坐姿。
- 原地跑：已有频率范围和反相测试，还需直接校验抬左膝时右肘前摆、两次落脚之间的相位连续、进退摆幅和暂停恢复，不能只断言常量为 1.2。
- 需要修改视觉参数时一次只改一类，保留录屏对照；不要同时顺带改寻路、识别或全局速度。

```sh

npm run dev
```

打开 `http://127.0.0.1:5173/examples/?mode=manual`。源码变化后手工构建，或另一个终端运行 `npm run build:watch`。

另一终端再执行：

```sh
npm run test:browser
mkdir -p .artifacts && npm run test:package
MONO_VERIFY_RUN=naturalness-home npm run verify:demo
```

Windows Git Bash 可运行上述命令；Playwright 使用本机 Microsoft Edge。`verify:demo` 本身不启动服务，需先保持 `npm run dev` 运行。手机宽度模拟与短时 frameMs 不是手机真机或整页性能验收。

项目目前同时有 npm 与 pnpm 锁文件；遵循 `CLAUDE.md` 的 npm/`package-lock.json` 基线，不要混用安装工具把两套类型残留在 node_modules。当前环境曾出现同版本 Chai 声明重复；不要通过放宽严格检查掩盖，先核对依赖链接和锁文件。
