## 1. 实施前提与交付边界

第 1–11 节保留完整首版的实施与验收计划。第 12 节是首个闭环的历史记录，第 13 节记录后续预览版，第 14 节记录本轮版本升级；阶段验证不等于原始完整首版验收。公开 npm 发布已获用户授权，但本轮开发不自动执行发布，远端版本以 registry 查询为准；上传截图或调用收费服务仍需单独授权。

完整首版应交付：

1. 原生 TypeScript npm 包，ESM / CJS、类型声明及浏览器 ESM 产物。
2. DOM 分层识别、动态平台更新、滚动/移动跟随和单人物运动引擎。
3. 24 个标准动作定义、20 类触发及连续姿态求解。
4. 可运行的自定义 clip / action / trigger / SurfaceProvider 注册与卸载路径。

6. 单元、浏览器集成、性能和资源释放测试，以及真实设备验证记录。
7. 使用说明、能力边界、测试结果和已知限制；只有实际完成并验证的内容才能标为支持。

## 2. 分阶段实施

### M0：文档评审

**输入**：原始需求和本次四份文档。

**工作**：核对自动识别边界、Canvas 方案、24/20 数量、离屏语义、性能目标及后续扩展。

**退出条件**：用户明确批准编码范围；保留被修改的决策，不把未回答问题当作默认同意。npm 名称与许可证可以留到发布前决定，不阻止已授权的本地原型。

### M1：关键风险原型与测量基线

批准后优先验证最可能推翻架构的事项，而不是先制作漂亮首页。

1. 相同骨架与动作输入下对比小型 Canvas 2D 与 SVG，比较 CPU、绘制、掉帧和内存，不用不同复杂度实现得出结论。
2. 实现最小真实 DOM 平台测量，验证透明容器排除、纯色背景、文字分片、hover 平台和矩形裁剪。
3. 验证当前支撑在文档/嵌套滚动、fixed、sticky、正向轴对齐缩放下的锚点误差。
4. 验证 jump / fall / landing、平台突然消失和两段腿 IK。
5. 建立计时、几何诊断、浏览器与参考设备记录。
6. 核验当前系统与测试工具的支持范围；Windows 上的 WebKit 自动化不等于 iOS Safari 真机验证。

**退出条件**：输出实际数据并确认继续沿用设计；若精度、体积和帧预算冲突，先提出最小取舍并请求修订基线。不能仅以“看起来流畅”通过。

原型是验证工具，不作为未完成产品发布。临时代码和资源在正式实现中整合或清理，不留下两套引擎。

### M2：生命周期、包入口与场景数据骨架

依赖 M1 的基本方案通过。

- 建立包构建与声明输出，保证 import 无 DOM 副作用。
- 实现 start / pause / resume / destroy、暂停原因集合、单循环和资源清理。
- 建立来源代次、平台版本、Anchor、FrameSnapshot 与局部索引。
- 落实集中读取/写入、扫描预算和缓存上限。
- 实现基本 Provider 注册、关键 key 测量与注销失效。

**退出条件**：Node / SSR 安全导入；重复创建/销毁无活动资源残留；模拟场景数据测试可以独立于 DOM 运行。模拟场景仅验证数值内核，不替代后续 DOM 识别测试。

### M3：识别与坐标闭环

- 常见边框、纯色块、文字片段、简单 SVG、open Shadow DOM 与 slot。
- 裁剪、部分遮挡、身份变更、失效队列、字体加载与重排。
- 当前支撑、目标和碰撞邻域优先刷新；无 Mutation 的 CSS 状态同样能更新。
- 文档和嵌套滚动参考系、空中滚动、被动离屏/恢复、移动可视视口。
- 支持调试查看真实检测结果；调试关闭时不能保留全页可视化成本。

**退出条件**：识别和坐标专项用例通过；同一个平台不因一次采样分段失去身份；未知证据不会被误当成有效落脚点。

### M4：运动、动作与交互

- 走跑加减速、制动距离、受限跳跃、扫掠碰撞和单向平台下穿。
- 完成 24 个动作、20 类触发、优先级、冷却和有种子随机。
- 完成融合、距离驱动步态、FK / IK 和接触交接。
- 人物点击/靠近和宿主 click / hover / focus，验证事件透传。
- 双轴循环、重新进入、暂停策略和 reduced-motion。
- 完成自定义动作与 Provider 的真实接入案例。

**退出条件**：所有预置有独立进入条件与可观察表现；安全中断不等待装饰动画；扩展不需要修改核心状态机即可接入已有运动能力。

### M5：单页演示与端到端验收

- 单页整合五个原始场景及补充区域。
- 同时提供自由游走和可重复的“定位到场景/触发动作/复位”控制。
- 示例只从构建产物导入包，不复制人物逻辑。
- 启动本地开发服务，在真实浏览器操作黄金路径、边界和回归场景。
- 调整小尺寸动作辨识度、视觉衔接和控制面板可用性。

**退出条件**：SC-01—SC-05 都有自动断言和人工复核记录；不能只通过类型检查便宣布 UI 功能完成。

### M6：性能、兼容性与打包验收

- 在普通页面和压力页面分别测试帧预算、发现成本、内存、资源释放与宿主影响。
- 验证 Chromium / Firefox / WebKit 自动化、实际 Chrome / Edge，以及 Safari / 手机真机。
- 核验 npm tarball 中的入口、类型、CSS、tree shaking 和文件白名单。
- 记录无法获得的设备或浏览器，标为未验证，不能视为自动通过。
- 根据测量优化，不引入未经需求确认的新架构或默认联网依赖。

**退出条件**：验收矩阵无未解释失败；未验证项目明确披露并由用户决定是否接受。仅本地生成发布候选，不自动上传或发布。

## 4. 测试分层

### 4.1 纯数值单元测试

推荐 TypeScript 测试运行器，实施时核验并锁定版本；不因测试工具而增加核心运行时依赖。

- 坐标正反变换、嵌套参考系组合、锚点重投影。
- 区间合并/裁剪、局部索引和版本失效。
- 跳跃可达性、制动距离、终端速度、扫掠最早接触。
- 单向平台和 drop-through 令牌释放。
- 步态相位、角度最短路径融合、骨长不变和 IK 极限。
- 有种子随机、动作冷却、事件仲裁和状态转换。
- 缓存淘汰、部分扫描提交、Provider 失效和动作依赖卸载。

纯 DOM 模拟环境无法真实排版，不能用 jsdom 中手工伪造的 DOMRect 验证页面识别准确率。

### 4.2 真实浏览器集成测试

以 Playwright 的 Chromium / Firefox / WebKit 为主要自动化通道，实际工具版本和浏览器二进制在实施时锁定。测试读取引擎调试快照以及独立计算/人工标注的期望几何，不把检测器自己的输出再当作正确答案。

黄金路径必须操作真实 DOM：隐藏、移除、折叠、滚动、设置纯 CSS 动画、点击按钮和改变文字宽度。只有运动内核测试可以注入合成数值平台。

### 4.3 真机与人工视觉复核

重点覆盖中端 Android 手机、iOS Safari、60 Hz 和高刷新率屏幕。桌面 CPU 降速只能补充测试，不能替代弱 GPU、移动视口、触摸滚动和内存限制。

人工检查慢速回放和正常速度：脚滑、接触穿透、转向突变、动作辨识度、突然悬空、人物遮挡业务以及用户交互被干扰。

测试截图只保存在本地且来自专用夹具；真实业务页面截图必须另外得到授权。未经授权不上传到第三方分析服务。

## 5. 五个场景验收用例

### T-SC01：文字跨越

- 前置：人物被显式定位到已识别的文字片段，固定种子；文本含中文、英文、空格、逗号、句号、emoji、组合字符和跨 span 的词。
- 操作：请求沿平台行走/跑动，改变容器宽度使文字换行，再切换已加载字体。
- 断言：空格/指定标点形成间断；跨越进入相邻有效片段；不改写 DOM 文本；换行后旧特征不会错误吸附到另一行。
- 反例：透明段落外框不能提供整段地面，UTF-16 代理对不能被拆分，RTL 片段不按逻辑顺序误连。
- 视觉：脚点对齐约定的文本度量支撑线；不以字形墨迹顶部作为错误的绝对断言。

### T-SC02：按钮远跳

- 前置：两按钮均有可见边框或可区分填充，尺寸和间距可控。
- 操作：分别设置短间距、立定可达距离、只有助跑可达距离和任何预置都不可达距离。
- 断言：选择相应步跨/跳跃；助跑速度连续；不可达请求返回原因而非瞬移；中途平台在实际下降路径上先接触时能提前落地。
- 边界：目标在起跳后移走、隐藏、缩小或快速运动，不瞬间改轨追赶；按当前物理继续下落。

### T-SC03：表格下跳

- 前置：至少三层单元格，当前平台上方和下方均有细线。
- 操作：定位第一层并请求 drop-through。
- 断言：只忽略原支撑，穿过后及时释放令牌，在首个有效下方单元格落地。
- 边界：原单元格删除、重新编号、合并单元格、下一层被遮挡，令牌不错误匹配其他平台。

### T-SC04：面板消失

- 前置：分别处于 idle、sit、wave 和起跳准备阶段；面板下有可开关平台。
- 操作：分别 display:none、remove、祖先隐藏、opacity 过阈值；不依赖库专属按钮通知。
- 断言：下一个可执行帧解除明确失效支撑；不等装饰动作完成；下方有效则落地，无平台则坠落并从上边界重新进入。
- 边界：恢复同一个 DOM 节点不自动恢复已失效的旧锚点；全页无平台时不无限同步重生。

### T-SC05：树节点折叠

- 前置：人物站在深层子节点，子节点仍保持 isConnected。
- 操作：分别通过 details / open、display 切换，以及容器高度收缩加 overflow 裁剪折叠父节点。
- 断言：前两类以及明确折叠造成的支撑消失进入坠落；不能仅以 isConnected 判断有效；动画折叠在支撑区间消失时释放。
- 对照：仅滚动把同一个节点移出可视区域，应该保留锚点并隐藏暂停，不能误作树折叠坠落。

### 6.1 精度门槛草案

以下阈值用于支持范围内的标准夹具，不扩展为“所有网页准确率”。批准前均为建议值。

- 稳定轴对齐 DOM 平台：接触点与预期支撑线误差 ≤ 1 CSS px。
- 支持的缩放/滚动组合：稳态误差 ≤ 2 CSS px；不出现持续累积漂移。
- 无主动行走时，支撑脚相对平台漂移 ≤ 1 CSS px；不同字体的 Range 与墨迹差异另记，不计为滚动误差。
- 明确平台删除/隐藏：在下一次可执行 rAF 校验中解除接触。主线程本身被阻塞时不能按墙钟保证 16 ms。
- 固定种子的常规薄平台下落与跳跃用例不得出现穿透；随机性不能成为偶发失败的解释。
- 可见性夹具按预先标注的“支持/不支持/未知”分组统计。支持组目标 precision ≥ 98%、recall ≥ 90%；检测器对支持组正例返回 unknown 或拒绝时计漏检，不能事后将该正例移出分母。
- 透明无绘制容器、明确已删除来源等硬性负例应零误接触，不能用总体准确率抵消严重错误。

支撑线人工标注与夹具计算规则独立保存于测试数据，不能作为运行时识别输入。边界容差、色差和采样参数如需调整，要保留调整前后结果及原因。

#### 识别精度的计分口径

以**可用支撑线的 CSS px 长度**为统计单位，而不是返回的 Surface 条数。这样一条正确平台分成数段不会天然提高或降低分数。

1. 每个夹具预先标注来源、实际几何特征、方向和可用区间；同一特征重叠的真值区间先求并集。来源映射由测试夹具建立，不作为运行时识别提示。
2. 输出只有来源/特征对应、方向相同且法向位置在几何容差内时才能匹配；普通轴对齐夹具容差为 1 CSS px，已标记的缩放组合为 2 CSS px。多个候选对应同一真值时按最大交叠、稳定标注顺序消歧，不重复分配同一真值长度。
3. `TP` 为成功匹配且去重后的真值覆盖长度；`FP = 所有有效预测区间长度之和 − TP`；`FN = 真值可用长度 − TP`。重复预测不能增加 TP，重复长度计入 FP；跨空格或遮挡错误连成的区间也计入 FP。
4. `precision = TP / (TP + FP)`，`recall = TP / (TP + FN)`，跨采样时刻先累计长度再求比率。没有预测而有真值时 recall 为 0、precision 标为未定义；全负例单独报告误报长度，不能用空分母获得满分。
5. 在固定视口、种子及字体加载完成后，以启动后 1 秒、规定操作后 1 秒的快照评估普通发现精度，不允许等待检测全部成功后才选择采样点。动态失效的下一帧响应另按专项用例评价，并同时报告发现时延与 unknown 数量。
6. 按文字、边框、纯色块、SVG 和裁剪子组分别报告，再给总体结果；不能让一条很长且容易检测的边框掩盖整类文字平台的漏检。

## 7. 性能与资源测量

### 7.1 基准场景

| 夹具 | 规模与用途 |
| --- | --- |
| F-Small | 约 500 DOM 节点、常见文本/按钮/表格，检查基本体验 |
| F-Normal | 约 5,000 DOM 节点、混排文本与 1,500 平台缓存上限，正式普通负载目标 |
| F-Large | 约 50,000 DOM 节点、多数离屏，验证分片和有界缓存，不承诺全页即时全识别 |
| F-Churn | 局部内容持续增删、虚拟列表复用、CSS 平移和 hover，验证失效合并 |
| F-Scroll | 长页面和两层滚动容器，60 Hz / 高刷新率滚动与空中轨迹 |
| F-Busy | 主线程人工长任务和页面动画负载，对比模块关闭/开启后的额外影响 |
| F-Lifecycle | 100 次创建、启动、销毁以及组件重复挂载，检查遗留资源与引用 |

测试输入固定，种子及设备条件记录。F-Large / F-Busy 是压力与降级验证，不把其结果冒充正常场景的性能保证，也不能借压力场景免除无限队列等正确性缺陷。

### 7.2 测量流程

1. 同设备、同浏览器、同页面参数分别运行模块关闭与开启两组。
2. 预热约 10 秒，正式采样 60 秒，重复至少 5 次；移动设备记录温度/电量/省电模式影响，避免只取最佳一轮。
3. 分开记录启动发现、稳定动画、滚动、DOM 高频变更、后台恢复与销毁。
4. 用性能标记统计模块关键路径和追加扫描；观察器/事件回调另统计总耗时，不能藏到帧预算外。
5. 同步 DOM API 引起的强制布局计入模块触发成本，浏览器 paint / composite 则在 Performance trace 中单独记录。
6. 记录 P50 / P95 / P99、最大连续任务、平台数量、扫描队列峰值和降级次数。
7. 比较宿主输入反馈和帧间隔变化；Long Tasks / Long Animation Frames 等 API 不可用时使用浏览器性能录制，不伪造跨浏览器相同支持。
8. 内存先热身，再在可控制环境比较 GC 后保留对象及堆快照；单个瞬时堆读数不能证明没有泄漏。

### 7.3 建议性能目标

| 指标 | 目标 | 备注 |
| --- | --- | --- |
| 默认入口 minified + gzip | ≤ 45 KiB | 包含 24 动作/20 触发；不含声明/示例/可选资源，静态 CSS 若有则单独并列报告 |
| 动画关键路径 P95 | 桌面 ≤ 2 ms；中端手机 ≤ 4 ms | 当前支撑测量、物理、姿态和绘制；不是整页总帧时间 |
| 新发现/精化额外预算 | 默认 ≤ 2 ms；移动低功耗档 ≤ 1 ms | 与关键路径分别计量，不能把两者合计宣传成只有 2 ms |
| 连续执行任务 | 不由模块正常工作产生 ≥ 50 ms 任务 | 外部宿主长任务另外标记；模块触发的布局不能排除 |
| 新增稳定 JS 堆 | F-Normal 目标 ≤ 8 MiB | 像素/GPU/合成缓冲另报；非统一浏览器可直接读取的单值 |
| 帧表现 | 无重负载时接近设备刷新率；高刷不改变运动速度 | 使用帧间隔分布和真机观察，不只展示平均 FPS |
| 缓存与队列 | 不超过设计限额，超限可解释降级 | 当前接触/目标不能被普通 LRU 淘汰导致误坠落 |
| 销毁 | 无活动监听、观察、帧任务和实例保留 DOM 引用 | GC 时机不确定，不要求销毁瞬间进程内存归零 |

性能目标达不到时，先定位 DOM 测量、候选数、Canvas、姿态求解或宿主压力中的真实原因。不要直接加入 Worker、WebGL 或 will-change，也不要为了测量好看关闭必须的支撑校验。

### 14.1 已实现的改动

- 两个入口导出 `VERSION`，示例和安装说明引用包元数据，npm lockfile 保留 npm 自动同步的版本字段。
- 对外重力默认 `9.8 m/s²`，允许连续有限值 `4–20`，内部固定 `100 CSS px/m` 换算；跳高仍为 CSS px，下落速度默认限制为 `600 CSS px/s`。规划、首次命中和实际积分共用限速前后的分段公式，水平匀速与竖直加速形成抛物线，不以缓动曲线替代物理。
- 高落地按人物自身下降路程判定，排除滚动并在下方循环重入时重置；空间足够时同一步进入翻滚。翻滚按撑手、肩背承接、错开收腿、展腿起身组织，窄平台安全缓冲。主动从 fill 下穿时暂时排除同实体内部文字，避免落回自己的标签，并有来源代次、穿出/新接触/循环/销毁及 5 秒期限的清理途径。
- 当前 20 个可请求动作增加坐姿、疑问、原地跑和攀爬。坐姿锁定后撑双手、臀部和不对称脚跟；疑问单手揉头，原地跑用时间相位但不推进世界根。
- 攀爬来自真实 HTML 长竖边、纯色侧边和可可靠恢复的自身二维旋转实线，角度严格大于 80°且留足连续 2H 的抓点空间。空中先伸双手，抓住后稳定约 0.65 秒，再依次贴脚；最高 `0.4H/s`，每次移动一个肢体，另三点保留接触。明确的 climb 请求抓住目标边后沿该边完成，不为了缩短路线跳回平台；moveTo 仍能组合平台与边段，离边起跳从实际位置重新求解并校验首次落点。
- 接触使用互斥的 support / climb 锚点；未知绘制待验证而非删除，失效释放，离屏保留隐藏。取消空中请求不冻结物理，取消攀爬保留有效抓持。融合和参考系插值不采用未知几何，根与攀爬抓点路程一起插值，IK 不拉长骨段。
- 自主活动先选择可见可承载区间中的随机目的地，再逐帧规划；到达后同周期选新目标，随机点过近时用有界远端候选避免短暂清空目标。短休不清目标，途中低概率变更目标不瞬间改飞行速度。不可达时允许趋近的中间点、限频重规划与重选；手动目标不会消费旧自动任务的结果。
- Dijkstra 保留 64/48 候选上限，预处理、索引构建和边检查可续跑，每帧默认 1 ms 软预算并限制单片工作量。结果检查目标、接触代次与相关几何；共同平移可继续投影，不因无关发现无穷重启。
- 滚动/视口变化将旧客户区几何标记为 unknown，新接触前以六子步窗口有界预测并重测可能碰到的来源，避免在旧屏幕坐标落地后跳到画外。预测只读数值状态，不推进世界根；邻域发现和同元素多特征测量仍共享原扫描路径。
- 快照和 navigationchange 记录目标编号、位置、距离、原因、路线状态、候选/展开/边检查数、累计规划耗时和重规划。debug 历史最多 32 条、深复制，不泄露 DOM 引用或页面内容；示例以 250 ms 周期显示。
